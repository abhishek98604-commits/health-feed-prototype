# Health Feed · interactive prototype

A 2017 concept for a health feed of short articles written by doctors, rebuilt in 2026 as a clickable, mobile-first prototype for my portfolio.

- **Live prototype:** https://abhishek98604-commits.github.io/health-feed-prototype/
- **Phone-frame version (for embedding):** https://abhishek98604-commits.github.io/health-feed-prototype/embed.html

## What you can do

- Scroll the feed, like and save articles, search, and filter by topic
- Open an article, read it, comment, and see more from the same doctor
- Open a doctor's profile, follow them and turn on new-article alerts
- See followed doctors' articles under **Following**, and saved articles in the menu

## Notes

- Colours, type (Open Sans) and card layout follow the original Figma design.
- Articles are sample content written for this prototype. They are not medical advice.
- Doctor names are fictional. Food and lifestyle photos marked in the code come from [Unsplash](https://unsplash.com); the rest are from the original design file.
- One HTML file, no build step. State lives in memory and resets on reload.
